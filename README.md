# Stone Paper Scissors Game

##  Project Overview

Stone Paper Scissors is a simple web-based game where a player competes against the computer.

The player selects one of three options — Stone, Paper, or Scissors. The computer randomly selects an option, and the game determines the winner according to the standard rules.

This project was created as a beginner-friendly web development project to understand basic HTML, CSS, and JavaScript concepts.

---

##  Features

-  Play Stone Paper Scissors against the computer
-  Choose Stone
-  Choose Paper
-  Choose Scissors
-  Computer generates a random choice
-  Displays the winner
-  Detects a draw when both choices are the same
-  Allows the player to play multiple rounds
-  Simple and user-friendly interface

---

##  Technologies / Tools Used

- **HTML** – Used to create the structure of the game
- **CSS** – Used for styling and designing the interface
- **JavaScript** – Used to implement the game logic and computer's random choice
- **Git & GitHub** – Used for version control and hosting the project
